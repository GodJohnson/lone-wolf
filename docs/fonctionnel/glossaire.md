# Glossaire métier — Lone Wolf Reader

Vocabulaire du jeu. Les termes anglais sont ceux des livres Project Aon et du code ; les termes français sont ceux de l'interface.

| Terme | Définition | À ne pas confondre avec |
|---|---|---|
| Section (*numbered section*) | Paragraphe numéroté du livre, unité de lecture et de navigation | Page (hors sections) |
| Page | Contenu hors sections : règles, disciplines, équipement, carte… | Section |
| Choix (*choice*) | Option proposée en fin de section, menant à une autre section | — |
| Habileté (*Combat Skill*, HAB / CS) | Caractéristique de combat | Quotient d'attaque |
| Endurance (*Endurance*, END / EP) | Points de vie. 0 = mort | — |
| Quotient d'attaque (*Combat Ratio*) | HABILETÉ effective du héros moins celle de l'ennemi | Habileté |
| Table de hasard (*Random Number Table*) | Tirage d'un nombre de 0 à 9 | — |
| Table des résultats de combat (*CRT*) | Pertes d'END selon le quotient et le tirage. `K` = tué net | — |
| Discipline | Compétence choisie à la création (ex. Weaponskill, Mindblast, Healing) | — |
| Feuille d'aventure (*Action Chart*) | Fiche du personnage : caractéristiques, disciplines, objets, or, repas | — |
| Série | Groupe de livres partageant des règles : Kaï (1-5), Magnakaï (6-12), Grand Maître (13-20), Nouvel Ordre (21-29) | — |
| Fin d'aventure (*deadend*) | Section qui met fin à la partie | Mort au combat |
